===========================
 CMS Restriction
===========================

A CMS Restriction in SAP Commerce is a rule used to control whether a CMS component or CMS page is displayed 
based on a specific condition, such as the current user, user group, time, or other business criteria.

---------------------------------------------------------------------------------------------------------------------------------
OOTB Restriction            Purpose
---------------------------------------------------------------------------------------------------------------------------------
CMSUserRestriction          Restricts CMS content to specific users.
CMSUserGroupRestriction     Restricts CMS content to members of specific user groups.
CMSTimeRestriction          Restricts CMS content to a specific time period.
CMSCatalogRestriction       Restricts CMS content based on catalog/version context.
CMSInverseRestriction       Negates another restriction — displays content when the referenced restriction evaluates to false.
CMSCategoryRestriction      Restricts CMS content based on the current category/context.
CMSProductRestriction       Restricts CMS content based on the current product/context.
---------------------------------------------------------------------------------------------------------------------------------

===========================
 Custom CMS Restriction
===========================

A Custom CMS Restriction is a developer-defined CMS restriction created when the standard SAP Commerce restrictions 
do not satisfy a specific business requirement. It uses a custom evaluator to determine whether the condition is satisfied.

==============CMSCorporateUserRestrictionEvaluator.java==============
package com.yourstanmay.core.restriction;

import com.yourstanmay.core.model.CMSCorporateUserRestrictionModel;
import de.hybris.platform.cms2.servicelayer.data.RestrictionData;
import de.hybris.platform.cms2.servicelayer.services.evaluator.CMSRestrictionEvaluator;
import de.hybris.platform.core.model.user.CustomerModel;
import de.hybris.platform.core.model.user.UserModel;
import de.hybris.platform.servicelayer.user.UserService;
import org.springframework.beans.factory.annotation.Autowired;

public class CMSCorporateUserRestrictionEvaluator implements CMSRestrictionEvaluator<CMSCorporateUserRestrictionModel> {

    @Autowired
    private UserService userService;

    @Override
    public boolean evaluate(final CMSCorporateUserRestrictionModel restriction, final RestrictionData context) {
        // 1. Check restriction is active or not
        if (!Boolean.TRUE.equals(restriction.getActive()))
        {
            return false;
        }
        final UserModel currentUser = userService.getCurrentUser();
        // 1. Check if user is logged in and is a Customer instance
        if (currentUser instanceof CustomerModel customer) {
            // 2. Fetch customer attribute isCorporateUser
            final Boolean isCorporate = customer.getIsCorporateUser();
            // 3. Return true if attribute is enabled, otherwise false
            return Boolean.TRUE.equals(isCorporate);
        }
        // Anonymous users or non-customer user types will not see the component
        return false;
    }
}
