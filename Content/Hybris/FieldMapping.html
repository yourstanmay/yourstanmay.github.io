------------Field Mapping in SAP Commerce----------

        ----Field Level Mapping----
        In SAP Commerce OCC, field-level mapping is used to control which fields of a DTO are exposed in the API response based on the requested field level.
        SAP Commerce commonly provides three standard field levels:

        BASIC → returns only the minimum required fields
        DEFAULT → returns the commonly required fields
        FULL → returns all available fields

        The client can request a particular field level through the OCC API.
            For example:
                ?fields=BASIC
                or
                ?fields=DEFAULT
                or
                ?fields=FULL
        
        We can create an additional custom field set level when we need a specific combination of fields.
        ?fields=YTS

        *******************************************************************************
            yourstanmayshoppingocc\resources\v2\yts-dto-level-mappings-v2-spring.xml
        *******************************************************************************

            <?xml version="1.0" encoding="UTF-8"?>
            <beans xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
                xmlns="http://www.springframework.org/schema/beans"
                xsi:schemaLocation="http://www.springframework.org/schema/beans
                http://www.springframework.org/schema/beans/spring-beans.xsd">

                <bean parent="fieldSetLevelMapping" id="walletDetailsWsDTOFieldSetLevelMapping">
                    <property name="dtoClass"
                            value="com.yourstanmay.occ.dto.customer.WalletDetailsWsDTO"/>
                    <property name="levelMapping">
                        <map>
                            <entry key="BASIC" value="walletId,balance"/>
                            <entry key="DEFAULT" value="walletId,userId,balance"/>
                            <entry key="FULL" value="walletId,userId,balance,status,error"/>
                            <entry key="YTS" value="walletId,userId,email,balance,currency,status,error"/>
                        </map>
                    </property>
                </bean>

            </beans>

        ----Custom Field Mapping----

            Custom Field Mapping is used when the default SAP Commerce mapping is not sufficient and 
            we need to apply custom logic while mapping data from one object to another.
            
            For example, if the source contains userId in lowercase but the API response requires it in uppercase, 
            we can use a custom mapper to transform the value before setting it in the DTO.
            
            It is also useful when a DTO field needs to be calculated, transformed, populated from multiple source fields, 
            or handled with specific business logic rather than being mapped directly.

            In our use case:
            WalletDetailsData → WalletDetailsWsDTO

            we use AbstractCustomMapper to apply this custom mapping logic.
            Mapping Direction
                mapAtoB() → Data → DTO
                mapBtoA() → DTO → Data

            In short:
                Field Set Level Mapping → controls which fields are included.
                Custom Mapper → controls how field values are mapped or transformed.


        *******************************************************************************
            yourstanmayshoppingocc\src\com\yourstanmay\mapping\WalletDataMapper.java
        *******************************************************************************

            package com.yourstanmay.mapping;

            import com.yourstanmay.facades.customer.data.WalletDetailsData;
            import com.yourstanmay.occ.dto.customer.WalletDetailsWsDTO;
            import de.hybris.platform.webservicescommons.mapping.mappers.AbstractCustomMapper;
            import ma.glasnost.orika.MappingContext;

            public class WalletDataMapper extends AbstractCustomMapper<WalletDetailsData, WalletDetailsWsDTO>
            {

                @Override
                public void mapAtoB(
                        final WalletDetailsData source,
                        final WalletDetailsWsDTO target,
                        final MappingContext context)
                {
                    /*
                    * Custom mapping logic
                    */

                    if (source.getUserId() != null)
                    {
                        target.setUserId(source.getUserId().toUpperCase());
                    }
                    if (source.getError() == null)
                    {
                        target.setError("No Error");
                    }
                    // Example custom field
                    // target.setMyCustomField(...);
                }
            }

                parent="abstractCustomMapper"/>
